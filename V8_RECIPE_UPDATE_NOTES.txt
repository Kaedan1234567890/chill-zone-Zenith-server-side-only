- Ender Crafting Table

The recipe-guide command automatically reads the same hardcoded sword recipes,
so its displayed grids will reflect these changes.

The custom tables use a server-side custom crafting system rather than normal
vanilla recipe-book recipes, so this build does not attempt to force those
recipes into the vanilla recipe book on an unmodded client.
