CHILL ZONE ZENITH - FIX 19
MOB DROP FIX

This is the SAME mod moving forward from Fix 18.

THE PROBLEM
===========
The custom materials existed, and ZenithGate already had a canDrop() check,
but no death event was actually registered to create the custom mob drops.

FIX 19
======
Adds a server-side Fabric AFTER_DEATH listener and spawns the matching custom
material IN ADDITION TO normal vanilla loot.

The drops only roll while their branch is ACTIVATED.

IMPORTANT
=========
Mansion Key is currently guaranteed from an Evoker while the Ravager branch is
active so you can test the progression immediately. The stricter original rule
(first qualifying Evoker in/near a Woodland Mansion) can be added after the
basic drop system is confirmed working.

===============
