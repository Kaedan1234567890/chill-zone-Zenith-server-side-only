CHILL ZONE ZENITH - LUCKPERMS PERMISSION NODES
================================================

PLAYER RECIPE GUIDE (public fallback)
-------------------------------------
chillzonezenith.command.crafting.recipe
Command:
  /zenith crafting recipe <category> <weapon>

This one defaults to AVAILABLE for normal players.
LuckPerms can explicitly deny it to any group/player.

These default to vanilla operator/gamemaster access when LuckPerms
does not explicitly set the node.

EXAMPLE GROUP SETUP
-------------------
Members:
  /lp group members permission set chillzonezenith.command.crafting.recipe true

Mods (example):
  /lp group mod permission set chillzonezenith.command.status true
  /lp group mod permission set chillzonezenith.command.detect true

Admins (example):
  /lp group admin permission set chillzonezenith.command.* true

Owners (example):
  /lp group owner permission set chillzonezenith.command.* true

You can override ANY individual node with true/false for owner, admin,
mod, members, or an individual player.
